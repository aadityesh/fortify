# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and respectful, assume good intent, and keep discussion
about the work. Harassment of any kind isn't tolerated.

Report unacceptable behaviour to the maintainer through
[a private security advisory](https://github.com/aadityesh/fortify/security/advisories/new)
or a direct message on GitHub. Reports are handled confidentially.
